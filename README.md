# ML HyperLab

Laboratorio interactivo para experimentar con algoritmos de Machine Learning,
visualizar resultados y ajustar hiperparametros en tiempo real.

## Funcionalidades

- Comparacion de modelos de clasificacion y regresion.
- Importacion de datasets CSV personalizados.
- Visualizacion de metricas, fronteras de decision y curvas de entrenamiento.
- Configuracion de algoritmos como XGBoost, Random Forest, KNN, redes neuronales,
  arboles de decision y regresion logistica.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma

## Desarrollo

```bash
npm install
npm run dev
```

La aplicacion queda disponible en `http://localhost:3000`.
